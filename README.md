# Shanghai Wander: Vibe & Vision

![Teaser Figure: Interactive Map Interface Showing City Walk Routes with Filters and User Reviews](assets/teaser_map.png)

## Abstract
*Shanghai Wander: Vibe & Vision* is an interactive city-walk route visualization designed for young tourists and residents in Shanghai who have limited leisure time and prioritize short, high-quality urban exploration. Focusing on five representative city-walk routes—Yuyuan Road, Anfu Road, Wukang Road, People’s Square, and Huaihai Road—the project integrates official cultural tourism data with community-generated content such as user reviews, photos, and price indicators. Through an interactive Google Maps–based interface with filtering, route overlays, and a conversational chatbot, users can compare online representations with real-life experiences and make informed travel decisions. The prototype aims to address information asymmetry in “internet celebrity” tourism, promote responsible consumption, and encourage sustainable urban exploration. As a community-based learning visualization, the project demonstrates how multi-source data and interactive design can support critical reflection, civic awareness, and ethical tourism practices aligned with SDG 11 and SDG 12.
